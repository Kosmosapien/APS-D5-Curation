Conectar à coleção privada

As fotografias não são públicas. A interface usa um token pessoal do GitHub exclusivamente para ler as prévias e registrar seus votos no repositório privado.

Permissões necessárias, restritas ao repositório APS-D5-Curation-Data: Contents: Read e Issues: Read and write. Criar token com permissões preenchidas.

O token permanece apenas na sessão deste navegador e não é enviado ao site público. Pode ser necessário digitá-lo novamente se o aplicativo fechar.

Como corrigir o erro 403 e entrar pelo celular
  1. Abra o link Criar token acima e entre na conta GitHub que tem acesso a Kosmosapien/APS-D5-Curation-Data.
  2. Em Resource owner, selecione Kosmosapien. Em Repository access, escolha Only select repositories e marque exclusivamente APS-D5-Curation-Data.
  3. Em Repository permissions, selecione Contents: Read-only e Issues: Read and write. Salve e copie o token gerado.
  4. Volte a esta página, cole o token e pressione Entrar e abrir curadoria. O token não deve ser enviado por mensagem ou colocado em links.

Se o repositório privado não aparecer para seleção, confira se a conta GitHub é a proprietária ou tem acesso. Uma conta conectada ao GitHub no navegador não autoriza automaticamente esta aplicação.
